# NUSC — الصفحة الداخلية (بعد تسجيل الدخول)

تنظيم الملفات (مش كله في ملف واحد):

```
nusc-platform/
├─ index.html        الرئيسية / لوحة الكلية
├─ materials.html     مستودع الكتب والمحاضرات
├─ ai-hub.html        المساعد الذكي المركزي
├─ profile.html       الملف الشخصي الكامل
├─ css/
│  ├─ base.css        الهوية المشتركة (أبيض + ذهبي)، الشريط العلوي، القائمة الثلاث نقط، الشريط السفلي
│  └─ colleges.css     الـ Hero + أنيميشن كل كلية (موتيف بسيط بلون الكلية الخفيف فوق الأبيض/الذهبي)
└─ js/
   ├─ colleges-data.js  مصدر بيانات الكليات الوحيد — زوّد كلية هنا وهتظهر في كل الصفحات تلقائي
   ├─ app.js            منطق مشترك: الكلية الحالية، القائمة، رسم الموتيف
   ├─ home.js           خاص بالرئيسية (تبديل الكلية للمعاينة)
   ├─ materials.js       خاص بصفحة المقررات
   ├─ ai-hub.js          خاص بصفحة الذكاء الاصطناعي
   └─ profile.js         خاص بصفحة البروفايل
```

## ملاحظات مهمة قبل الربط بالباك إند

- **المساعد الذكي**: الواجهة بتوهم إنها أداة واحدة موحّدة (شرائح المصادر شغالة كلها مع بعض بدل قائمة اختيار)،
  لكن الدمج الفعلي بين Gemini / ChatGPT / Claude / NotebookLM لازم يحصل من **سيرفر عندكم**، مش من المتصفح —
  علشان مفاتيح الـ API الخاصة بكل خدمة متتسربش في كود الواجهة الأمامية. الملف `js/ai-hub.js` فيه شرح تفصيلي.
- **رفع الكتب/الفيديوهات**: الفورم في `materials.html` شكل ووظيفة بس، لسه محتاج endpoint حقيقي للرفع والتخزين.
- **البروفايل**: البيانات الشخصية حاليًا Placeholder — لازم تتربط ببيانات التسجيل الفعلية.
- **صفحة تسجيل الدخول والتسجيل** اتسابت زي ما هي زي ما اتفقنا، الشغل كله هنا كان على الصفحات اللي جوه.

## إزاي تضيف كلية جديدة
عدّل `js/colleges-data.js` بس، وحدد `motif` من: `molecule` `circuit` `paw` `atom` `chart` `wave` `pulse` —
أو زوّد موتيف جديد في `renderMotif()` داخل `js/app.js`.
